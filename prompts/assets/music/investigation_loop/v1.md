# Investigation loop: v1

- **Tool:** `facebook/musicgen-small (transformers)`, run locally on CPU (227 s)
- **Settings:** 30 s, seed 1, guidance 3.0, sampling on
- **Status:** selected

## Prompt

```
Minimal ambient underscore for a detective game, quiet and tense, soft low synth pad, a few muted piano notes, subtle pulsing cello ostinato, 70 bpm, sparse and steady, unobtrusive background music under dialogue, no lead melody, no drums.
```

## Result

Quiet, low and steady (41 % below 200 Hz, RMS -25.7 dBFS raw), sections change about every 7 s. A few soft attack transients in the first 12 s from the pulsing ostinato, no drum kit. Stays under dialogue.

**Post-processing:** Trimmed 0.25 s at each end, last 1.5 s crossfaded into the start for a seamless loop, RMS -24 dBFS → `music/investigation_loop.ogg`.
