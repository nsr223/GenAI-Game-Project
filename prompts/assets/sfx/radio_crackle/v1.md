# Radio crackle: v1

- **Tool:** `cvssp/audioldm-s-full-v2 (diffusers)`, run locally on CPU (40 s)
- **Settings:** 3 s, seed 1, 100 steps, guidance 2.5
- **Status:** selected

## Prompt

```
Short burst of static crackle from a handheld walkie-talkie
```

**Negative prompt:** `music, low quality`

## Result

Static bursts from 0.3 s on, 91 % of the energy between 1 and 4 kHz, typical of a band-limited radio.

**Post-processing:** First 1.4 s after the onset → `sfx/radio_crackle.ogg`.
