# Storm window: v1

- **Tool:** `cvssp/audioldm-s-full-v2 (diffusers)`, run locally on CPU (117 s)
- **Settings:** 10 s, seed 1, 100 steps, guidance 2.5
- **Status:** selected

## Prompt

```
Heavy rain and strong gale wind beating against a ship window, stormy sea waves
```

**Negative prompt:** `music, speech, low quality`

## Result

Broadband rain/wind noise with gust swells every 0.5–1 s, steady overall (0.8 dB spread). Usable as the outside-weather layer that never calms (World §7.3).

**Post-processing:** Seamless loop, RMS -30 dBFS → `ambience/storm_window.ogg`.
