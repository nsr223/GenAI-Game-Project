# Mess hall: v1

- **Tool:** `cvssp/audioldm-s-full-v2 (diffusers)`, run locally on CPU (109 s)
- **Settings:** 10 s, seed 1, 100 steps, guidance 2.5
- **Status:** selected

## Prompt

```
Rain against a window, quiet ship hum and the occasional clink of a coffee mug
```

**Negative prompt:** `music, speech, low quality`

## Result

Rain-like texture with scattered small clinks (2–8 kHz transients), quieter than the technical rooms (RMS -27 dBFS raw). Matches the warmer living space.

**Post-processing:** Seamless loop, RMS -30 dBFS → `ambience/mess_hall.ogg`.
