# Medical bay: v1

- **Tool:** `cvssp/audioldm-s-full-v2 (diffusers)`, run locally on CPU (220 s)
- **Settings:** 10 s, seed 1, 100 steps, guidance 2.5
- **Status:** selected

## Prompt

```
Low ventilation hum and a soft refrigerator hum in a small clinic room
```

**Negative prompt:** `music, speech, silence, hiss, beeping, low quality`

## Result

Steady hum (73 % below 200 Hz) under a bright broadband hiss; level spread only 0.4 dB. Same fault as dry lab v2, so corrected the same way.

**Post-processing:** 2 kHz low-pass, seamless loop, RMS -34 dBFS → `ambience/medical_bay.ogg`.
