# Page turn: v1

- **Tool:** `cvssp/audioldm-s-full-v2 (diffusers)`, run locally on CPU (57 s)
- **Settings:** 5 s, seed 1, 100 steps, guidance 2.5
- **Status:** selected

## Prompt

```
Pages of a paper notebook being turned
```

**Negative prompt:** `music, speech, low quality`

## Result

Two groups of paper rustles (1.3–2.2 s and 3.4–3.7 s), 99 % of the energy above 1 kHz as expected for paper.

**Post-processing:** Leading silence trimmed, first page turn only (1.0 s), peak -4.5 dBFS → `sfx/page_turn.ogg`.
