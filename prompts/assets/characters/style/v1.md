## Style block (paste at the end of every portrait prompt)

```
Style: ink and wash illustration, graphic-novel realism. Confident fine black ink linework with light cross-hatching in the shadows, loose watercolor washes on top, visible paper texture. Muted palette of slate grey, steel blue and desaturated navy, with warm amber accent light. Realistic adult proportions, natural faces, no caricature. Soft warm key light from the upper left, cool blue fill from the right, as if lit by a ship's cabin lamp on a stormy morning.
Composition: single character, waist-up, three-quarter view, body turned slightly toward the right of the frame, centered with some empty space above the head. Plain flat light-grey background (#D9D9D9), no scenery, no props in the background, no floor shadow, clean silhouette edges so the figure can be cut out.
Format: portrait orientation, 2:3 aspect ratio.
```

## Avoid (paste as negative prompt, or as "Do not include: …" for chat-based generators)

```
text, letters, logos, watermark, signature, brand names, red cross emblem, blood, injuries, weapons, holding tools as weapons, scenery, room background, multiple people, cropped head, anime style, 3D render, photorealistic photo, glossy digital painting, cartoon, exaggerated features, villain expression, smirk, sci-fi clothing, uniforms with insignia of real organizations
```

## Workflow notes

1. **Anchor first.** Generate Thomas first and compare him with Erik's mockup. Once he matches, use that image as the **style reference** (image input / "same style as the attached image") for all other characters.
2. Keep the generator, model and (if available) seed the same for all characters. Record them in each prompt file.
3. Generate 2–4 candidates per character, pick one, save the prompt result in the character's file (`Result:` section) with the date and tool.
4. **Cut-out:** remove the grey background (e.g. `rembg`, remove.bg, or Photoshop/GIMP) and export as transparent PNG.
5. Export name: `<character_id>_neutral.png` (e.g. `maya_chen_neutral.png`), matching the IDs in `data/npcs.yaml`.
