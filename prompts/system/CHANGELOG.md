# System prompt changelog

Engine-owned prompts. Each change gets a new version file plus one line here (AGENTS.md §8).
The active versions are set in `data/rules.yaml` → `prompts`.

| Date | File | Version | Change and reason |
|---|---|---|---|
| 2026-11-20 | `npc_rules/` | v1 | First version. Global NPC rules from Story §11 / Evidence §7 (via `docs/summaries/npc-prompts.md`), rewritten to be **spoiler-free**: every NPC receives this text, so it must not name the murderer, time, weapon or place (the summary's "never change the murderer, time (22:45 / 23:10)…" would leak those to all NPCs). Rule 7 added so NPCs don't announce access the engine hasn't granted. |
| 2026-11-20 | `npc_template/` | v1 | First version. Section order: rules → persona → unlocked facts → own claims → scene → presented evidence. Locked facts are omitted by the engine rather than "hidden" by instruction (npc-prompts summary: leaving X out beats "don't tell X"). |
| 2026-11-20 | `npc_rules/` | v2 | First live leak probes (`transcripts/2026-11-20_npc_rules-v1_gemini-3.5-flash.md`): Maya **invented a checkable alibi and a terminal log** (decides a TBD), and Thomas named a non-existent **"Captain Vance"**. New rule 3 forbids inventing specific times, places, names, records or events (incl. one's own movements) and gives a vague-answer pattern instead; rule 4 points at the new cast list; rule 6: don't confirm/deny/hint at things about yourself you weren't given. |
| 2026-11-20 | `npc_template/` | v2 | Adds `## People aboard` (`$cast`: the 8 people, names and roles only) so NPCs stop inventing crew. A/B on gemini-3.5-flash-lite: v1 "Captain Vance" → v2 "Captain Morgan"; v1 invented alibi → v2 "I'd need to check my notes". |
| 2026-11-20 | `npc_rules/` | v3 | v2 over-corrected (`transcripts/2026-11-20_AB_npc_rules-v2_…`): Sarah sent the player to "Dr. Chen or the science team" for wet-lab access (wrong: World §5.3, Sarah controls access; and it steers suspicion), Olivia deflected a medical question to "someone else". Rule 3 now allows general statements from one's own role; rule 8 says the captain decides access and, as captain, asks for a formal request. A/B v3: Sarah "make a formal request for access", Olivia "haven't completed my full assessment". Single samples per probe; Maya's alibi answer still hints at a location (borderline). |
